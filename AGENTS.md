# CalcU — Standing Orders (user-locked)

## Taste (locked)
Pure Material 3 expressive only. WinUI/Fluent never comes back — no Microsoft
binaries, no Fluent tokens in new work. Drawer + rail + expanded pane, never a
crowded bottom bar. Single-accent discipline, tonal surfaces, dynamic color safe.

## Proof standard (locked)
Every claim is proven: CI log excerpt + downloadable APK link
(`https://github.com/omersusin/CalcU/releases/download/latest/app-release.apk`).
Never assert green, built, or uploaded without checking. If the user says
"you can check", check with tools and show evidence.

## Scope control (locked)
Propose packs, user picks, then build. Never add tool packs unprompted.
Sensitive categories (pregnancy, ovulation, alcohol, medical diagnosis) are
excluded by default — ask first.

## "From scratch" (locked)
Means depth-first rebuild energy on the existing repo. Never wipe git history.

## Engineering (locked)
- Depth, not stubs: every tool computes for real, unit-tested.
- Zero `!!`, total cores, runCatching + error text in UI, cancellable loops.
- Licenses: GPL/PolyForm/unlicensed repos are ideas-only, never copied.
  Apache-2.0/MIT may be used as deps with attribution in Settings.
- After every push: watch CI to the end, fix reds, refresh release APKs.
- Skills before work: compose, android-ux, design-taste for UI; systematic-debugging for bugs.
